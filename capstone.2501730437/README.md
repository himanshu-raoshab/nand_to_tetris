# Nand to Tetris Capstone — Roll No. 2501730437

## Personal values
- K = last two digits = 37
- K mod 3 = 1: assembler must report invalid instructions with source line numbers
- K mod 4 = 1
- Box starts at screen row 37; height 20 rows; width = 16 × (1+1) = 32 pixels (2 words)
- First screen word address = SCREEN + 32×37 = 16384 + 1184 = 17568

## Folder structure
- `part_a/`: add your verified CPU.hdl, Memory.hdl and Computer.hdl plus any dependent chips from your lab.
- `part_b/assembler.py`: two-pass Hack assembler with line-numbered errors.
- `part_c/Box.asm`: key-controlled box program.
- `part_c/Box.hack`: generated by running the assembler.
- `tests/`: put official `.tst` and `.cmp` files here.
- `report/`: report template and screenshot checklist.

## Requirements
Python 3.9+ and the official Nand2Tetris tools (Hardware Simulator and CPU Emulator).
Download the official software from https://www.nand2tetris.org/software.

## Run the assembler (Windows)
1. Install Python 3.
2. Open this project folder in VS Code.
3. Open Terminal → New Terminal.
4. Run `python --version`.
5. Run `python part_b/assembler.py part_c/Box.asm`.
6. It creates `part_c/Box.hack`.

## Run Box.hack in CPU Emulator
1. Open the Nand2Tetris CPU Emulator.
2. Load the Hack computer platform.
3. Load `part_c/Box.hack` as the ROM program.
4. Run continuously (or use the emulator's run control).
5. Press a key in the Keyboard input area: the 32×20 black rectangle should appear.
6. Release/clear the keyboard input: the rectangle should disappear.
7. Take a screenshot showing the screen and keyboard state.

If your emulator version has a keyboard input panel, click it and enter a key. If it does not accept live keyboard input, use the emulator's keyboard control as documented in the installed version.

## Important correction / verification
The start address is 17568 because one screen row contains 32 words: 16384 + (32×37) = 17568.
The program writes two consecutive words on each of 20 rows, then advances 32 words to the next row.

## Test the K-specific assembler feature

```

```
Run:
`python part_b/assembler.py bad_test.asm`
